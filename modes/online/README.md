# 联机模块

已接入 main.cpp：菜单进入联机大厅，支持创建对局、输入 IPv4 加入、实时落子同步及胜利提示。返回菜单、Esc 和退出程序都会释放连接。

## 接口

- 保存一个 `OnlineSession session`，无需复制会话。
- 点击事件调用 `onlineClick(session, x, y)`；返回 true 时切换回菜单。
- 键盘字符调用 `onlineKey(session, key)`，用于 IPv4 输入框。Esc 由主循环处理。
- 每帧先调用 `session.update()`，再调用 `drawOnlineScreen(session, mouseX, mouseY)`。
- 进入联机模式时、Esc 离开联机模式时调用 `session.reset()`；析构也会释放网络资源。
- 若主循环需要胜利弹窗，应读取 `session.game.winner`，而不是其他模式的 game。

## 连接与规则

创建方监听所有 IPv4 网卡的 TCP 18888 端口。双方先进入房间，连接后任意一方选择黑白棋，另一方自动获得相反颜色，黑棋先手。房主统一发送选色结果，同时选择时以房主已确认的结果为准。选色前不允许落子。
同机连接填 127.0.0.1，局域网连接填创建方 IPv4 地址。
创建和加入接口允许指定其他端口，页面默认端口固定为 18888。
IPv4 输入框点击后显示边框和闪烁光标；接受数字、点、退格，支持左右键、Home、End、Delete；Enter 加入。点击输入框时光标定位到末尾。
连接/握手超时为 10 秒，等待玩家加入没有超时。
每个连接只进行一局；失败、断开或结束后返回菜单重新进入。
发送成功表示已进入发送队列，不表示对方已确认；断线后本局停止，不支持续局。
局域网连接还需要创建方防火墙允许入站，网络不能隔离两台设备。

## 协议

固定 6 字节消息：版本、类型、行、列、步号高字节、步号低字节。
版本为 2，两端需使用新版程序。首包是握手：类型 0、行字段为棋盘边长，其余为 0。
类型 2 为加入方选色请求，类型 3 为房主确认结果，行字段为请求方或房主的棋色，其余字段为 0。网络事件按收到顺序处理，避免选色与首步合并到达时乱序。
棋步消息类型为 1，步号是落子前的棋步数，从 0 开始，大端序。
接收方检查协议、坐标、步号、回合、空位与游戏状态；异常则关闭连接。
网络层保留未完整接收/发送的数据，按消息长度拆包，不把一次 recv 当成完整消息。
