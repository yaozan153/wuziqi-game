# 本地棋谱与回放

本地对局落子后，点击“保存棋谱”保存当前棋局。未结束的棋局也可以保存；悔棋后保存的是当前剩余棋步。

保存时可在弹出的输入框中命名，支持中文，最多 80 字；留空使用保存时间，取消则不保存。同名会自动添加数字后缀，不覆盖旧棋谱。无需手动填写 `.gmk` 扩展名。

文件位于运行程序旁的 `records` 文件夹，名称为本机保存时间，扩展名为 `.gmk`。同一秒重复保存会添加数字后缀，不覆盖旧棋谱。VS Code 调试版本会保存在调试程序旁。

主菜单“历史棋谱”显示保存的文件，点击打开后从第 0 步开始，使用“上一步”“下一步”查看。“返回列表”用于选择另一份棋谱，“返回菜单”或 Esc 退出。回放不会落子，也不会弹出胜利提示。

未结束的棋谱会显示“继续本地对局”，点击后恢复到存盘时的最后一步，进入本地双人对局；复盘当前停在哪一步不影响恢复结果。续玩后仍可悔棋和另存棋谱。已获胜或棋盘已满的棋谱只允许回放。

`record.h / record.cpp` 负责文件读写及棋步校验，`history.h / history.cpp` 负责列表和手动回放界面。

格式示例（行列从 0 开始，1 为黑棋、2 为白棋）：

```text
WUZIQI 1
13
6 6 1
6 7 2
```

读取时检查版本、棋盘大小、棋子颜色、回合、坐标、重复落子和获胜后继续落子，格式不合法的文件会显示错误。
